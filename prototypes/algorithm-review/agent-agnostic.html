Proposed design
The shared record

Exact promises live with beans.

Durable Objects hold versioned intents, requests, replies and accepted promises. Every agreement keeps its author and history.

Optional recall

Find useful past experience.

Cloudflare Agent Memory could surface earlier approaches and lessons. It is in private beta; recalled context stays linked to its sources.

Any agent, any harness

Carry context through tools.

Plugins expose the same repository tools through MCP. Each agent keeps its own working memory and chooses what to share.

# Collaboration trial

Do not change the protected tests or package scripts to make your implementation pass.
Implement only your assigned module. Publish approaches, negotiate precise cross-module
semantics and pin shared promises using Beanstalk MCP tools. Tokens belong in private
runtime files outside this repository; never print or commit them.

The trial's coordinator may commit and merge branches. Participant agents should return
their finished file changes for review; the coordinator controls integration.
